# Fotos da produção (estúdio Jacarandá)

Nomes de arquivo que o site espera. Os arquivos atuais são **stand-ins** (gerados no Higgsfield)
com o mesmo enquadramento; ao subir as fotos reais com estes nomes, o site troca sozinho.

| Arquivo | O que é | Proporção |
|---|---|---|
| `medicos-trio-horizontal.jpg` | Os três, foto principal da home (Dr. Breno em pé à esquerda, Dra. Ana Paula sentada, Dr. Túlio em pé à direita) | 3:2, ≥ 2400 px de largura |
| `medicos-trio-vertical.jpg` | Os três, versão vertical (mobile) | 2:3, ≥ 1600 px de largura |
| `dr-tulio-bovo.jpg` | Dr. Túlio Bovo sentado na poltrona | 2:3 |
| `dr-breno-gondim.jpg` | Dr. Breno Gondim sentado na poltrona | 2:3 |
| `dra-ana-paula-bovo.jpg` | Dra. Ana Paula Bovo sentada na poltrona (colete camel) | 2:3 |
| `dra-ana-paula-bovo-02.jpg` | Dra. Ana Paula Bovo, terno branco (cenário com estante) | 2:3 |

Como subir: no GitHub, abrir a pasta `assets/img/producao/` na branch de trabalho → **Add file → Upload files**,
soltar os arquivos com estes nomes e confirmar. JPEG, qualidade 80–85, sem perfil de cor exótico.
